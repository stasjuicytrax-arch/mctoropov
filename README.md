# MC TOROPOV — редизайн stastoropov.ru
Vite + ванильный JS. ТЗ — `01-TZ.md`, дизайн-система — `00-DESIGN-SYSTEM.md`.

## Команды

```
npm install
npm run dev       # dev-сервер :5173, заявки принимает заглушка в vite.config.js
npm run build     # прод-сборка в dist/
npm run preview   # посмотреть собранное
npm run pages     # пересобрать страницы направлений из content/
```

`predev` и `prebuild` сами запускают `scripts/build-pages.mjs`.

## Как устроена сборка

| Что | Где |
|---|---|
| Главная | `index.html` + `src/sections/00…19-*.html`, подключаются через `<!-- @include … -->` (плагин в `vite.config.js`) |
| Страницы направлений | **генерируются** `scripts/build-pages.mjs` из `content/` в корневые `weddings.html`, `cityholiday.html`, `korporat.html`, `privatparty.html`, `graduationday.html`. Править генератор или `content/`, а не HTML |
| Юридические страницы | `privacy.html`, `terms.html` — обычные файлы, точки входа `src/styles/legal.css` и `src/scripts/legal.js` |
| 404 | `404.html` |
| Стили | `src/styles/tokens.css` — единственный источник значений; дальше база, компоненты, сквозные системы, секции |
| Скрипты | точки входа `main.js` (главная), `page.js` (направления), `legal.js` (юридические) |

На Vercel `content/` не уезжает (`.vercelignore`), поэтому генератор там ничего не перезаписывает — в деплой идут уже собранные HTML. Их надо коммитить.

## Деплой

Проект на Vercel (`stastoropov-site`, команда `stas8`) подключён к этому репозиторию: **каждый пуш в `main` автоматически пересобирает прод**.

- Живая ссылка: https://stastoropov-site.vercel.app
- Ручной деплой, если нужен: `vercel deploy --prod --yes --scope stas8`
- Форма заявок (`api/lead.js`) ждёт переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`; без них отвечает 503.

## Коротко о проекте
Одностраничник ведущего Стаса Торопова. Вся информация и порядок блоков берутся со старого сайта, меняется подача: чёрная база, кислотный лайм, рваные края между секциями, крупная типографика, много движения. Референсы — в папке `Referens`.

Внутренние страницы (5 направлений, галерея, отзывы, блог) — вторая очередь, контент для них уже готов в `content/04-cases.md`.

## Что не сделано и почему

- **Галерея, страница отзывов и благодарностей, «Для агентств»** — нет материала: сканов писем, видеоотзывов, условий для подрядчиков. Пункты «Галерея» и «Блог» скрыты из меню до появления страниц.
- **Блок «Что входит»** на страницах направлений временно наполнен тарифами из `content/05-pricing.md` — отдельных текстов под направления пока нет (подробности в комментарии `scripts/build-pages.mjs`).
- **Открытые точки, которые ждут клиента:** номер счётчика Яндекс.Метрики, токен Telegram-бота и почта для заявок, PDF презентации, название телепроекта, подпись под фото с МОТ, логотипы компаний и фото публичных персон, реквизиты оператора персональных данных для `/privacy` и `/terms`.

## Что ещё нужно от клиента
Список в `01-TZ.md` §9. Главное: нормальная фотосессия, видео-исходники, актуальная презентация и правовая проверка блока с публичными персонами — часть фото там из ТАСС и РИА Новости.

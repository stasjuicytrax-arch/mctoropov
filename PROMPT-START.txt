Собираем сайт ведущего Стаса Торопова. Рабочая папка — текущая.

Сначала прочитай целиком, до единой строчки кода:
- 01-TZ.md — техническое задание, карта из 19 блоков
- 00-DESIGN-SYSTEM.md — визуальный закон проекта
- tokens.css — готовые CSS-переменные
- 02-AUDIT.md — что было сломано на старом сайте
- content/01-main-page.md, 02-faq.md, 03-reviews.md, 04-cases.md, 05-pricing.md — весь контент, он уже собран и выверен
- content/06-assets-review.md — разбор медиа в assets/, какие файлы куда годятся

Контент не придумывай и не сокращай — он весь лежит в content/. Медиа не ищи — всё в assets/.

Стек: Vite + чистый HTML/CSS/JS, без React и без Tailwind. Lenis для скролла, GSAP + ScrollTrigger для анимации, three.js для 3D-объекта в hero. Шрифты Unbounded, Onest, JetBrains Mono — скачай в woff2 локально в /fonts, subset cyrillic+latin, никаких обращений к Google CDN в продакшене. Одна секция = один CSS-файл + один JS-модуль. Все значения только из tokens.css, хардкод цветов и размеров запрещён.

В работе обязательно используй два установленных скилла:
- design-taste-frontend — прогоняй preflight перед тем, как считать секцию готовой
- impeccable — /impeccable typeset после текстовых блоков, /impeccable polish перед сдачей секции
Дизайн-систему им отдавай нашу (00-DESIGN-SYSTEM.md + tokens.css), готовые UI-киты не подключай. Все флаги детектора разбирай, неразобранных не оставляй. Отдельно сверяйся со списком запретов в 00-DESIGN-SYSTEM.md §14.
